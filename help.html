Quick guide for using the Grand Vista Hotel Management System

🚀 Getting Started

Welcome to the Grand Vista Hotel Management System! This application helps you manage bookings, track guest information, and handle reservations efficiently.

Logging In

  • Navigate to the login page (index.html)
  • Enter your staff credentials
  • Click "Login" to access the dashboard

User Menu

  • Click on your initials (top-right corner) to view your profile
  • Click "Logout" to safely exit the system

➕ Creating a New Booking

Follow these steps to create a new reservation:

Step 1: Guest Information

  • Full Name: Enter the guest's complete name as it appears on their ID
  • Contact Number: Provide a valid phone number for communication
  • Age: Record the guest's age (must be 18+ for primary bookings)
  • Address: Enter the guest's full residential address
  • ID/Passport Number: Record official identification number for verification

Step 2: Room Selection

  • Room Type: Select from Normal, Semi Luxury, or Luxury
  • Bed Type: Choose Single, Double, or King
  • Breakfast: Include or exclude breakfast in the booking
  • Number of People: Specify total guests (affects pricing)

Step 3: Stay Duration

  • Check-in Date: Select the arrival date
  • Check-out Date: Select the departure date
  • Total Cost: Automatically calculated based on selections

Step 4: Confirmation

  • Review all entered information carefully
  • Click "Create Booking" to save the reservation
  • You'll be redirected to the Reservations page upon success
  • Use "Cancel" to return to the dashboard without saving

💡 Tip

All fields are required. Make sure to collect complete information from the guest before starting the booking process.

📅 Managing Reservations

The Reservations page displays all active bookings with several management options:

Viewing Reservation Details

  • Click the "View" button next to any reservation
  • A modal window displays complete guest and booking information
  • Review room type, bed type, dates, and guest details
  • Click outside the modal or press the "×" button to close

Editing an Existing Reservation

  • Click the "Edit" button next to the reservation
  • You'll be taken to the Edit Reservation page (amber theme)
  • Modify any booking details as needed
  • Click "Update Reservation" to save changes
  • Use "Cancel" to return without saving changes

Generating Bills

  • Click the green "Bill" button next to a reservation
  • The system generates a detailed invoice showing:
    • Guest name and reservation ID
    • Room charges breakdown (per night rates)
    • Bed type charges
    • Breakfast charges (if included)
    • Total number of nights
    • Final total amount in Rs
  • Click "Print / Download PDF" to save or print the bill
  • Click "Close" to return to the reservations list

Deleting a Reservation

  • Click the red "Delete" button next to the reservation
  • Confirm the deletion when prompted
  • The reservation will be permanently removed from the system

⚠️ Warning

Deleting a reservation is permanent and cannot be undone. Always verify with a supervisor before deleting active bookings.

⚙️ System Settings (Managers Only)

The Settings page allows managers to configure global hotel parameters:

Room Availability Configuration

  • Navigate to the Settings page from the navigation menu
  • View the current total capacity for each room type (Ordinary Room, Semi Luxury, Luxury)
  • To modify a capacity, click the "Edit" button next to the room type
  • The selected room type and its current capacity will populate the input form
  • Enter the new total rooms capacity and click "Update" (or "Save")
  • A success message will confirm the changes have been saved

ℹ️ Note

This page is restricted to users with the MANAGER role. Other staff members will not see the Settings link in the navigation menu.

💡 Tips & Best Practices

  • Double-check dates: Always verify check-in and check-out dates with the guest to avoid errors
  • Verify guest information: Ensure contact numbers and ID numbers are accurate for communication and legal compliance
  • Review pricing: Before finalizing bookings, confirm the total cost matches guest expectations
  • Use View before Edit: Always view a reservation's details before making edits to understand the current booking
  • Generate bills promptly: Create and print bills during check-out to maintain efficient workflow
  • Regular system checks: Review the reservations list daily to stay updated on upcoming check-ins and check-outs
  • Data accuracy: All reservation data is stored in the system's database, so accuracy is crucial for reporting

🔧 Troubleshooting

Reservations Not Loading

  • Check your internet connection
  • Verify the backend server is running (http://localhost:8081)
  • Refresh the page (F5 or Ctrl+R)
  • If the issue persists, contact IT support

Cannot Create Booking

  • Ensure all required fields are filled in
  • Check that dates are valid (check-out must be after check-in)
  • Verify the guest age is 18 or above
  • Make sure contact number and ID are properly formatted

Bill Not Printing Correctly

  • Use the "Print / Download PDF" button in the bill modal
  • Ensure your browser's print preview shows only the bill (not the reservation list)
  • Check printer settings and paper availability
  • Try using "Save as PDF" option if direct printing fails

Lost Session / Logged Out

  • Simply log in again using your credentials
  • Your work is saved automatically, so no data is lost
  • Avoid long periods of inactivity
